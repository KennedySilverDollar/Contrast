# フェーズ P8: 硬化と API 凍結の準備

## 読むもの
- docs/core-spec.md 全体
- docs/core-plan.md の 5 節「テスト方法」

## やること
1. `cargo mutants -p contrast-core` を全体に対して実行し、生存ミュータントを一覧にする。
2. 生存ミュータントごとに、それを殺すテストを tests/impl_*.rs か src/verification/extra/ に足す。
   殺せない（等価ミュータントなど）と判断したものは docs/mutants.md に理由を書く。
3. `cargo llvm-cov -p contrast-core --all-features` で行カバレッジを測り、95% 未満なら
   通っていない分岐のテストを足す。結果の要約を docs/coverage.md に書く。
4. 全公開項目の doc コメントを見直し、各関数に「エラー条件」と「守る不変条件の番号」を書く。
5. `cargo doc -p contrast-core --no-deps` が警告なしで通ることを確認する。

## やらないこと
- 実装の振る舞いを変えない。テストで見つかった不具合は修正してよいが、報告に必ず列挙する。
- タグを打たない。`v0.1.0` は人間が打つ。

## 完了条件
- scripts/verify.sh --full が緑。生存ミュータントはすべて殺したか docs/mutants.md に理由がある。
- 行カバレッジ 95% 以上。
- CLAUDE.md の「報告の形式」で報告して終わる。
