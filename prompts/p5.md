# フェーズ P5: レイアウト参照実装

## 読むもの
- docs/core-spec.md の 4 節 I5、5 節の Layout、7 節 D4・D8・D9
- crates/contrast-core/tests/spec/spec_layout.rs
- crates/contrast-core/src/verification/spec/layout.rs

## やること
1. layout/columns.rs に `Columns`（Layout の参照実装）を作る。
   窓 n 枚を作業領域の `split_columns(n)` で均等列に並べ、`windows` の順に左から割り当てる。
   n == 0 なら out に何も追加せず Ok。幅不足は `LayoutError::AreaTooSmall`。
2. `arrange` は `out` を clear してから書く。`out` の順序は `windows` の順序と同じ。
3. lib.rs から `Columns` を再エクスポートする。
4. P4 の再レイアウト処理に、Layout が返した矩形の検証を入れる（外部実装の Layout も想定した防御）。
   作業領域からはみ出す部分は作業領域との intersect で切り詰める。切り詰めで空になる場合、
   または Tiled 窓同士が重なる場合は `Err(CoreError::Layout(LayoutError::AreaTooSmall))` を返す。
5. tests/impl_layout.rs に 1〜64 枚のプロパティテストを足す（I5 を確認）。

## やらないこと
- 他のレイアウト方式（タイル分割・スクロールなど）を作らない。方式は未決事項。
