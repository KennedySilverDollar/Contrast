## やること
1. crates/contrast-core/src/domain/geometry.rs に Point, Size, Rect を実装し、上の仕様テストと
   Kani ハーネスを全部通す。`mod verification;` は P0 で済んでいる。`src/verification/extra/mod.rs` に `pub mod geometry;` を足す。
2. 型の要件: Point, Size, Rect, LayoutError は Debug, Clone, Copy, PartialEq, Eq を derive する
   （LayoutError は Copy 不要）。Point は `Point::new(x, y)` と `x()` `y()`、
   Size は `width()` `height()` を持つ。
   `Size::new(w, h) -> Option<Size>` は w >= 1 かつ h >= 1 のときだけ Some。
   `Rect::new(x, y, w, h) -> Option<Rect>` は Size の条件に加え、右端 x+w と下端 y+h が
   i32 に収まるときだけ Some。
3. Rect に次を実装する。すべて checked 算術で、パニックしない。
   - アクセサ: x, y, width, height, right（= x+width）, bottom（= y+height）,
     center（= Point(x + width/2, y + height/2)、整数除算）
   - `contains(Point) -> bool`（右端・下端は含まない半開区間）
   - `intersect(&Rect) -> Option<Rect>`
   - `split_columns(n: usize) -> Result<Vec<Rect>, LayoutError>`
   - `split_rows(n: usize) -> Result<Vec<Rect>, LayoutError>`
   split は幅（高さ）を n で割った商を各要素に、余りを先頭から 1 ずつ配る。
   n == 0 または幅（高さ）< n なら `Err(LayoutError::AreaTooSmall)`。
4. LayoutError は src/error.rs に置く（この時点では AreaTooSmall のみ）。
5. lib.rs から geometry の公開型と LayoutError を再エクスポートする。
6. 不足していると思う性質は tests/impl_geometry.rs と src/verification/extra/geometry.rs に足す。
   最低限、intersect の対称性と、intersect 結果が両方に contains されることを入れる。
